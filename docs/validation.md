- 实际安装 ASAR 内 35 个运行文件与最终构建逐字节一致；安装包没有礼物素材或 Matter.js。
- 首页、书架、时间商店在 4 种尺寸和 4 种缩放下共 48 组布局检查没有横向溢出，已查看代表实图。

## 连续绘制与一小时内存

对象为实际安装的 v1，隔离数据，内容 1352×731 CSS px、DPR 1.25、中档。采用项目既有离屏持续绘制配置。顺序与原验收一致：先 20 轮页面切换和 100 次真实时间兑换，再固定暖机 5 分钟，随后正式采样 3602.44 秒，每 30 秒记录一次，共 120 个正式样本。

全程不强制 GC、不清缓存、不重启窗口、不改变采样段。总 private bytes 按暖机末 5 次与正式末 20 次各自中位数计算：**367.07→374.04MiB，增长 6.97MiB，满足 ≤16MiB**。实际提交绘制 p95 **20ms**，满足原 ≤26.4ms 门槛。正式每段真实绘制至少 1513 帧，没有把遮挡暂停当成低负载通过。

| 进程    | 暖机末中位数 MiB | 正式末中位数 MiB | 差值 MiB |
| ------- | ---------------: | ---------------: | -------: |
| Browser |            82.77 |            89.29 |    +6.52 |
| GPU     |           195.98 |           196.74 |    +0.76 |
| Utility |            11.42 |            11.65 |    +0.23 |
| Tab     |            76.57 |            76.95 |    +0.38 |

分进程中位数差不必等于先合计后取中位数的差。记录了原始分进程内存、JS 堆、DOM、监听器和真实绘制直方图；不以几何/纹理数量稳定代替内存结果。

这次通过整体移除收藏、拾取、物理和动态热区路径，保留单水面，收敛了资源与 DOM 生命周期。上述实测证明本候选满足当前场景预算；没有声称已经单独证明旧草稿 61.16MiB 增长的某一条泄漏保留链。

## 排除的诊断与边界
