## 本次明确的产品方向

保留学习首页、学习记录、课程资料、时间商店、设置与积水效果。彻底移除随机掉落、拾取、物品仓库、收藏展示、出售和积分系统。奖励由用户自定义，以分钟标价，直接扣减可用时间；累计学习与每日学习记录不减少。

保留草稿里与本方向一致的课程书架、稳定计时布局和原生全屏改进。旧模型、物理引擎、热区回调、全页面 MutationObserver、素材生成及收藏测试脚本移除。所有页面只共用一个水面；重复样式入口合并，过时需求、素材预览和重复截图从当前目录移除，由 Git 历史和本地源码归档追溯。

## 数据迁移约定

schema1-3 的 SQL 和校验保持原样，schema4 增量迁移兼容已发布数据与未发布草稿。迁移真实路径数据库前自动保存 `.before-v4`，不删除用户原附件。

- 保留会话、累计学习、每日切片、课程、资源、外观、笔记和历史奖励收据。
- 旧奖励价格按原约定 `1 积分 = 60 秒` 转为毫秒价格，用户可继续编辑。
- 删除转换时间的旧扣款，按历史已完成购买重新记录其实际消耗的学习时间；旧积分购买总扣款最多为历史用于转换的学习时间。宝贝出售所得积分不会凭空变成学习收入。
- 收据保留当时奖励名和等价报价 `price_amount`，`charged_ms` 单独记录实际扣掉的学习时间。出售积分资助的历史购买可能实际扣时为零；不产生负余额。新兑换报价与实际扣时一致。
- 清除旧积分／收藏操作的缓存收据和相关表，取消旧积分待确认报价；旧学习时间兑换的已确认收据继续幂等返回。
- 新版完整备份使用 schema4，仍可导入 schema1-3 备份。旧程序不能写升级后的 schema4 数据。

## 旧内存证据的边界

旧候选记录为总 private bytes 中位数 545.35→606.52MiB，约增加 61.16MiB，主要来自 renderer，其次 GPU；这是旧草稿的失败结果，并非 v1 实测。本次移除相关整个生命周期与渲染链路后重新验收，不能仅用模型数量稳定或一次短测推断长期没有增长。

采用 [Electron 性能指南](https://www.electronjs.org/docs/latest/tutorial/performance)、[Chrome 内存分析](https://developer.chrome.com/docs/devtools/memory-problems)、[Three.js 资源释放](https://threejs.org/manual/pages/how-to-dispose-of-objects.html) 的现有机制。研究了开源 [Meta MemLab](https://github.com/facebook/memlab) 的三快照分析能力；当前使用 Electron 已有 CDP 采样，没有将诊断框架加入生产依赖。
