# 收藏品素材

12 件轻量 GLB + 12 个本项目原创 SVG 缩略图，全部运行时离线读取。逐项模型名称、作者、来源页、许可证、原始文件、修改说明、SHA-256 和字节数见 `sources.json`。

- 听雨白石、春生嫩芽、森林小伞：Kenney Nature Kit，CC0；原包许可见 `Kenney-License.txt`。
- 其余九件：本项目原创程序化造型，生成源 `scripts/collection-assets.mjs`。采用瓷器、柔金属、浅色玻璃的统一陈列风格。
- 最高品质：跃龙门锦鲤寓意顺利上岸；金榜题名卷寓意金榜题名、得偿所愿。

稀有度与售价由应用定义，不是素材网站评级。白/绿/蓝/紫/金/红权重依次 5000/2800/1400/600/180/20（总和10000）；出售积分 1/2/4/8/20/60，每档两种不同轮廓。权威业务配置在 `src/shared/collection.ts`，物品获得时将品质和售价写入不可追溯改价的快照。

保留已下载的三个正式 Kenney 模型即可再生成其余资产；开发下载暂存和完整素材包不属于发行文件。任何新素材应逐项补充来源记录。
